# Pixel Live Webcam PC

Windows client that connects **Pixel Live** to your computer and turns your Android phone into a webcam and microphone.

Use Pixel Live with **OBS Studio, vMix, and other Windows applications**.

## ✨ Features

* 🎥 Pixel Live virtual camera for Windows
* 🎙️ Pixel Live audio support
* 📡 SRT video and audio streaming
* 🔄 Automatic device reconnection
* 🖥️ Designed for Windows
* 📱 Works with the Pixel Live Android app
* 🎬 Compatible with OBS Studio, vMix, and other compatible applications

## 🛠️ Installation

1. Download the installer.
2. Run `PixelLiveWebcam.Setup.1.2.1.exe`.
3. Follow the installation instructions.
4. During installation, you can choose whether to install **VB-CABLE** for Pixel Live audio.
5. Restart Windows if requested.
6. Start **Pixel Live Webcam PC**.
7. Open Pixel Live on your Android device and connect it to the computer.

## 🎙️ Audio

Pixel Live Webcam PC uses **VB-CABLE** to provide Pixel Live audio to Windows applications.

VB-CABLE is a separate third-party component developed and distributed by **VB-Audio Software**.

Its installation is optional. If you want to use Pixel Live audio in OBS, vMix, or another Windows application, install VB-CABLE during the Pixel Live setup.

More information:

https://vb-audio.com/Cable/

## 🔌 Requirements

* Windows 10 / 11 64-bit
* Pixel Live Android app
* Local network connection between the Android device and the computer
* VB-CABLE for Pixel Live audio
